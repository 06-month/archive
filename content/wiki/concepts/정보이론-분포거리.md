# 정보이론 · 분포 간 거리

**한 줄 요약**: "두 분포가 얼마나 다른가"를 재는 도구 묶음 — **엔트로피**(한 분포의 불확실성), **KL·JS divergence**(두 분포의 거리), **InfoNCE**(대조 학습으로 거리를 학습). 이 vault에서 3D Vision과 LLM/RL을 **가로지르는 유일한 수학적 다리**다: 매칭·자기지도·탐색·생성이 모두 같은 도구를 다른 목적에 쓴다.

> [!note] 앵커 노트
> 전용 raw 미수집. 각 논문 노트가 인용한 범위 안에서만 정리하며, 수식 상세는 해당 노트·원논문으로 넘긴다.

## 도구별 정의와 성질

**엔트로피** — 한 분포의 불확실성.
- **Shannon** $H_1=-\sum_a \pi(a)\log \pi(a)$: 가장 표준적이나 **크기만 알려주고 방향을 못 준다**. 어휘가 크고 heavy-tail이면 롱테일 노이즈에 흔들림.
- **2차 Rényi** $H_2=-\log\sum_a \pi(a)^2$ (collision probability): 제곱 때문에 **지배적 mode에 집중**하고 롱테일에 둔감 → 유효 support 크기의 robust한 근사.
- 핵심 함정: **엔트로피가 같아도 분포 모양은 전혀 다를 수 있다.** 스칼라 하나로 중요도를 재면 정보를 잃는다.

**KL divergence** $D_{KL}(p\|q)$ — 비대칭. $p$가 높은 곳을 좇는 **mode-seeking** 편향이 있어, "모델이 강하게 거부하는" 방향의 편차를 놓칠 수 있다.

**JS divergence** $D_{JS}(p\|q)=\tfrac12 D_{KL}(p\|m)+\tfrac12 D_{KL}(q\|m)$, $m=\tfrac12(p+q)$ — **대칭**이고 $[0,\log 2]$로 **유계**라 수치적으로 안정. 편차의 부호와 무관하게 총 분포 이동량을 잡는다.

**InfoNCE** — 분포 거리를 직접 계산하는 대신, **positive는 당기고 negative는 밀어내는** 대조 목적으로 표현을 학습. softmax 정규화가 사실상 커널 가중 역할을 한다.

## 이 vault에서의 쓰임 (같은 도구, 다른 목적)

| 목적 | 노트 | 쓰임 |
|---|---|---|
| **매칭** | [[MASt3R]] | dense feature 매칭 헤드를 **InfoNCE**로 학습 → 대응점 획득 |
| **자기지도·정렬** | [[VGGT-Ω]] | teacher-student 자기지도, register↔언어 **CLIP식 InfoNCE** 정렬 |
| **모션 분리** | [[MoRe]] | attention 분포를 조작(attention-forcing)해 동적·정적 분리 |
| **탐색 유도** | [[BeyondEntropy-ICT]] | **$H_2$·strategy purity**로 엔트로피 붕괴↔폭발 분기 판정, **JS divergence**로 unique token 선별 |
| **생성** | [[Drifting-Model-원스텝생성]] | 커널 softmax 정규화가 **InfoNCE와 동형**, 두 분포가 같아지는 지점($V=0$)을 평형으로 사용 |
| **생성 prior** | [[flow-matching-생성prior]] | 확산·flow matching이 노이즈↔데이터 분포를 잇는 경로를 학습 |

> [!important] 도메인을 가로지르는 관찰
> [[BeyondEntropy-ICT]](LLM/RL)와 [[Drifting-Model-원스텝생성]](생성)은 **"두 분포가 같아지는 지점을 신호로 쓴다"**는 구조를 공유한다 — 전자는 $\pi(a)\approx\beta(\pi)$인 **경계 토큰**을 골라 갱신하고, 후자는 $V_{p,q}=0$인 **평형**을 손실로 삼는다. 3D 쪽의 [[MASt3R]]·[[VGGT-Ω]]는 같은 InfoNCE를 **표현 학습**에 쓴다. 도구는 하나인데 목적이 매칭→탐색→생성으로 갈린다.

## 선택 기준 (실무)
- **대칭성이 필요**하면 JS. 비대칭 KL은 mode-seeking 편향이 붙는다([[BeyondEntropy-ICT]]가 KL·Wasserstein 대비 JS 우위를 실험으로 확인).
- **어휘가 categorical**이면 Wasserstein은 부적합 — ground metric(토큰 인덱스 간 거리)이 의미를 갖지 못한다.
- **롱테일 노이즈**가 문제면 Shannon 대신 $H_2$.
- 거리를 명시적으로 계산하기 어려우면 **InfoNCE로 우회**(positive/negative 샘플만 있으면 됨).
